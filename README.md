EDBPから、KEITO Cloud APIを利用してPythonコードのアップロード・実行・ログ確認・プロセス管理までを行えるプラグインです。

KEITO Cloud API keyの作成方法

1 Discord SERVERに参加

https://keitodaze.net/discord

2 https://cloud.keitodaze.net/ にアクセスし、アカウント登録する

3 Dashboardページが開けたら APIを押して、APIキーをコピーします


API KEYの設定方法

まず、プラグインをインストールしてください

1 下の設定マークを押す

2 API KEYとDiscord BOTのトークンを設定します

3 アップロードボタンを押し、「[22:02:07] アップロード成功 — File ID: 1024」と出たら通信成功です
