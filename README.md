# このプラグインの紹介

EDBPから、KEITO Cloud APIを利用してPythonコードのアップロード・実行・ログ確認・プロセス管理までを行えるプラグインです。

KEITO Cloud API keyの作成方法

①Discord SERVERに参加してください https://keitodaze.net/discord

② https://cloud.keitodaze.net/ にアクセスし、アカウント登録する

③ Dashboardページが開けたら APIを押して、APIキーをコピーします


# API KEYの設定方法

まず、プラグインをインストールしてください

1 下の設定マークを押す

2 API KEYとDiscord BOTのトークンを設定します

3 アップロードボタンを押し、「[HH:MM:SS] アップロード成功 — File ID: (NUM)」と出たら通信成功です
